## Prompt Saver 2.4.1

A small polish release on top of 2.4.0: a clearer, more prominent **update notification** and a tidied-up **changelog scrollbar**.

### Downloads

| File | Use it when |
|---|---|
| `Prompt.Saver_2.4.1_x64-setup.exe` | Installer — choose **all users** (admin) or **current user only**; upgrades replace the previous version automatically, your data is kept |
| `prompt-saver.exe` | Portable standalone version — one file, no installation |

Requires the Microsoft WebView2 runtime (preinstalled on Windows 11 and current Windows 10). If it is missing, the app offers the official Microsoft installer on first start.

### Improved
- The **update notification** is now a clearer, more prominent card — an icon, the new version, and a one-click **Install now** button — while still matching your chosen theme.

### Fixed
- The scrollbar in the update changelog now looks exactly like every other scrollbar in the app.

For the full 2.4.0 feature list (full-screen media viewer, redesigned tooltips, better screenshots, tidier expert menu), see the [CHANGELOG.md](../../blob/master/CHANGELOG.md).
